## Project Description
This project is a personal CV (Curriculum Vitae) webpage created as part of the GitHub and Personal CV assignment for IT415. It presents my profile, education, skills, and contact information in a simple, modern, and responsive single-page website built using only HTML, CSS, and JavaScript.

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Features
- Home / personal introduction section
- About Me / profile section
- Education section
- Skills section (organized as a skills grid)
- Contact information section
- Fixed navigation bar with smooth scrolling
- Mobile-friendly navigation menu (hamburger menu)
- Responsive layout for desktop, tablet, and mobile
- Subtle hover effects and scroll animations

## Project Structure
```
my-cv/
```

## How to Open the Webpage Locally
1. Download or clone this repository to your computer.
2. Open the `my-cv` folder.
3. Double-click `index.html` (or right-click it and choose "Open with" your browser).
4. The webpage will open directly in your browser. No installation, server, or database is required.
